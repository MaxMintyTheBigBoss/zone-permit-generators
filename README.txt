ГЕНЕРАТОР ПРОПУСКОВ (п. 14.3)
================================
Локальное приложение для подготовки заявления 14.3 и пропусков
(индивидуальных и транспортного) на въезд в зоны отчуждения.
Работает ПОЛНОСТЬЮ на компьютере — без интернета и без ИИ.

КАК ЗАПУСКАТЬ
-------------
- Готовый вариант (для конечных пользователей):
  дважды кликните на файл  Генератор_пропусков.exe
  (Python устанавливать не нужно — всё встроено в exe).
- Из исходного кода (для разработчика):
  pip install -r requirements.txt
  python app.py

КАК РАБОТАТЬ
------------
Откроется окно с тремя вкладками.

ВКЛАДКА «1. Заявитель и цель»
  1) Введите фамилию, имя, отчество, дату рождения, личный номер заявителя.
  2) Цель въезда:
     - «благоустройство места захоронения» — выберите кладбища из списка;
     - «свой вариант» — впишите свою цель в поле ввода;
     - можно написать любую цель вручную.
  3) Отметьте район(ы) из восьми. В списке кладбищ останутся только
     кладбища выбранных районов.
  4) Выделите (Ctrl+клик) нужные кладбища — это объекты визита.
  5) Если объекта нет в списке, впишите его в «Произвольный объект».
  6) Укажите срок действия (с/по) и дату заявления (подставится сегодня).

ВКЛАДКА «2. Пассажиры» (необязательно)
  Кнопкой «+ Добавить пассажира» добавьте строки: ФИО и дата рождения.
  На КаЖДОГО пассажира будет создан отдельный индивидуальный пропуск.

ВКЛАДКА «3. Авто и выдача»
  - Если въезд на автомобиле — отметьте галочку и впишите марку-модель и
    регистрационный знак (создастся транспортный пропуск).
  - Кому на согласование: выберите из списка (Т.М.Путькова / А.В.Соломейчук /
    В.О.Шабловский) или впишите своё.
  - Папка для сохранения (по умолчанию — подпапка output рядом с программой).

Нажмите «Сгенерировать документы».

ЧТО И ГДЕ СОЗДАЁТСЯ
-------------------
Внутри выбранной папки создаётся подпапка с датой и временем (ДД.ММ.ГГГГ.ЧЧ.ММ):
  Заявление_<Фамилия>.docx            — заявление на процедуру 14.3
  Пропуск_Заявитель_<Фамилия>.docx    — индивидуальный пропуск заявителя
  Пропуск_Пассажир_<Фамилия>.docx     — по одному на каждого пассажира
  Пропуск_Транспорт_<номер>.docx      — транспортный (если указан автомобиль)

Формат и внешний вид строго повторяют образцы — заменяются только
плейсхолдеры, шрифты/отступы не меняются.

ПАМЯТЬ (БАЗА ЗНАНИЙ)
--------------------
После генерации данные сохраняются в файл data\permit_history.json.
Если позже ввести те же ФИО — программа подскажет, что найдена прошлая запись.

СТРУКТУРА ПАПКИ
----------------
  Генератор_пропусков.exe   — программа (двойной клик)
  app.py / generator.py     — исходный код
  templates/                — шаблоны .docx (можно править)
  data/                     — база знаний (история пропусков)
  output/                   — куда по умолчанию сохраняются документы
  requirements.txt          — зависимости для сборки

ПЕРЕДАЧА ДРУГИМ ПОЛЬЗОВАТЕЛЯМ
-----------------------------
Скопируйте папку с приложением целиком (или один .exe) и отдайте.
Python не требуется. Нужна Windows.

ПЕРЕСБОРКА .EXE (для разработчика)
----------------------------------
  pip install pyinstaller
  python -m PyInstaller --noconfirm --onefile --windowed \
      --name "Генератор_пропусков" --add-data "templates;templates" app.py
